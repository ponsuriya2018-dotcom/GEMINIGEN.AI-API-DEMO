Get started

If you are new to GeminiGen AI, this section will guide you through getting the necessary data to get started.

Follow the tutorial to get you started and learn how GeminiGen AI creates quality images and videos

1. Get API key

Make sure you are the one requesting our service by using your API key. Follow the steps below to get your API key:

  • If you do not have an account, please create an account at geminigen.ai.

  • In Profile go to Integration then click Create API key button

  • Take the API key you just created and copy it to the APIs below to try.

2. Try the APIs

We provide some API you can by providing params like API key, prompt,...

Note: to use the APIs below, you must upgrade your plan to Premium.

AI Image Generator

Create stunning images from text prompts using advanced AI models. Enter your API key and prompt in the box below to generate an image now.

AI Video Generator

Create professional videos from text prompts using advanced AI models

Note: make sure you have configured Webhook URL to receive video results. If you don't have a webhook, configure it here. Additionally, your webhook must be designed to receive the correct payload format to receive the most accurate data.

3. Integrate API with your language

If you want to integrate with the programming languages you are using, visit the demo for specific instructions.
