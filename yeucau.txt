3. Trên trang html home, link đến 1 trang html đơn giản khác chứa code demo, hướng dẫn tích hợp và gọi api của geminigen.ai, bằng các ngôn ngữ như javascript, python, php
4. Trang README.MD chứa link đến các trang html trên
